# Расчёт 3D-печати по весу

Страница: https://inord.github.io/3d-print/

Загрузите модель STL, 3MF или OBJ: страница покажет модель, примерный вес пластика и цену печати. Файл никуда не отправляется, всё считается в браузере.

Библиотеки: [three.js](https://threejs.org) r147 и [fflate](https://github.com/101arrowz/fflate) 0.8.2, обе под лицензией MIT, тексты лицензий лежат в папке `vendor`.
